# Code

All software and firmware for the project.

## What to put here

- Firmware for microcontrollers (Arduino, ESP32, Raspberry Pi Pico, etc.).
- Scripts, apps, or data analysis.
- If you have more than one program, give each one its own subfolder, for example `code/firmware/` and `code/app/`.

## How to run it

Fill this in so someone else can run your code:

1. Tools to install (for example, Arduino IDE or Python 3.12).
2. Libraries to install.
3. How to upload or run it.

## Free tools

- [Arduino IDE](https://www.arduino.cc/en/software)
- [VS Code](https://code.visualstudio.com/) with [PlatformIO](https://platformio.org/)
- [Thonny](https://thonny.org/) for MicroPython
