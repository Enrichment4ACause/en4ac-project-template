# Docs

Anything written about the project.

## What to put here

- Research and sources you used.
- Design decisions: what you tried, what failed, and why you chose what you did.
- Test results and data.
- Presentations, posters, or reports (PDF).
- Photos and videos of the prototype. The main README links to `prototype.jpg` in this folder.

Markdown (`.md`) files show up nicely on GitHub, so use them for notes when you can.
