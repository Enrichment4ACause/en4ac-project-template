# Electronics

Schematics, PCB designs, and wiring diagrams.

## What to put here

- **Project files** from your ECAD tool, so others can edit them.
- **Schematic as PDF**, so anyone can read it without installing anything.
- **Gerber files** (zipped) if you order a custom PCB.
- **Wiring diagram or photo** if you built it on a breadboard or with jumper wires.

## Free tools

- [KiCad](https://www.kicad.org/) is free and open source. It does schematics and PCBs.
- [Fritzing](https://fritzing.org/) is good for breadboard wiring diagrams.
- [Wokwi](https://wokwi.com/) simulates Arduino, ESP32, and Raspberry Pi Pico circuits in the browser.
